# 🚀 Go Viral: AI Creator Assistant

**Predict Virality. Optimize Content. Stop the Scroll.**

Go Viral is a premium AI-powered platform designed for creators who want to master the algorithm. Using a custom Neural Scanning Engine, the app analyzes video/image pixels and captions to provide actionable insights that drive engagement.

---

## ✨ Key Features

- **🧠 Neural Virality Scoring:** Proprietary algorithm that scores your content from 0-100 based on current viral trends.
- **👁️ Visual Integrity Scan:** Analyzes brightness, exposure, and pacing to ensure high visual retention.
- **✍️ Semantic Hook Analysis:** Scans your captions for psychological triggers and "thumb-stopping" hooks.
- **📊 Competitor Comparison:** Real-time benchmarking against top creators in your specific niche (Tech, Lifestyle, Fitness, etc.).
- **🔥 Content Multipliers:** AI-generated optimized captions, viral hashtags, and trending audio recommendations.
- **📜 Analysis History:** Keep track of your content's evolution with a persistent history dashboard.
- **💎 Premium Aesthetics:** Fully responsive, high-performance UI featuring Glassmorphism, 3D scroll animations, and optimized typography.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15+ (App Router)
- **Styling:** Tailwind CSS + Vanilla CSS (Custom Glassmorphism System)
- **Animations:** Framer Motion (Scroll-triggered 3D effects)
- **Backend/Auth:** Supabase
- **Icons:** Lucide React
- **Typography:** Space Grotesk (Headings) & Inter (Body)

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/go-viral-ai.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env.local` file with your Supabase credentials:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
